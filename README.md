BoyNextDoor Fan Website
Project Overview

The BoyNextDoor Fan Website is a simple, user-friendly fan hub dedicated to the K-POP boy group BOYNEXTDOOR. With the rising global popularity of K-POP, many fans want an easy and centralised way to learn more about their favourite artists without needing to jump between multiple apps or social media platforms. This project aims to provide a clean and accessible space for both new and long-time fans to explore information about the group in one place.

Essentially, this website acts as a digital home for fans—offering updated details about the members, recent news, band achievements, merchandise, and upcoming concert schedules. It is designed to be visually appealing, straightforward to use, and fully dedicated to enhancing the fan experience.

Design Process

This website is created for K-POP fans, especially those who support BOYNEXTDOOR or are curious to learn more about the group. Users want a platform where they can quickly find reliable information, stay updated on recent activities, and access merchandise or concert tickets without hassle.
The project helps users achieve these goals by placing all fan-related content in one central location, making navigation simple and intuitive.

User Stories

As a new fan, I want to learn about each member so that I can familiarise myself with the group quickly.

As a longtime fan, I want to stay updated with the latest BOYNEXTDOOR news so that I never miss important announcements.

As a fan interested in merch, I want to browse and purchase official items so that I can support the group.

As a concert-goer, I want to view upcoming events and book tickets easily so that I don’t miss performances.

As a casual visitor, I want a simple navigation menu so that I can explore the site effortlessly.
